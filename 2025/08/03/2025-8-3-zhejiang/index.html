浙江游

一、时间安排

时间：2025.8.5 - 2025.8.9【周二 -> 周六】
车程：

  1. 汉口 -> 杭州西 8.5 上午 9:36
  2. 杭州西 -> 汉口 8.9 下午 16:13
  3. 杭州站 -> 义乌站 8.8 上午 8:20
  4. 义乌站 -> 杭州站 8.9 上午 8:14

注意事项：

  • 身份证
  • 泡面、面包、保温杯
  • 防晒装
  • 雨伞

二、行程安排

8.5 浙大

杭州西 -> 浙大紫金港校区

晚上 浙大附近

8.6 飞来峰

上午 紫金港 -> 浙大玉泉校区
下午 玉泉 -> 灵隐寺(飞来峰)

8.7 西湖

灵隐寺 -> 西湖断桥残雪 -> 白堤 -> 浙江博物馆(孤山) -> 坐船 -> 花港观鱼 -> 雷锋夕照

8.8 义乌

杭州站【8:20】 -> 义乌站【10:16】 -> 义乌国际商城 -> 1970文创园 -> 韩国风情街

8.9 杭州

义乌站【8:14】 -> 杭州站【9:52】 -> 杭州西【16：13】 -> 汉口【20:52】

三、预约

  1. 浙大紫金港校区 1~2d
  2. 浙大玉泉校区 1~2d
  3. 浙江博物馆 7d

四、美食

杭州酒家【西湖附近】 西湖醋鱼
知竹【灵隐寺附近】
